## How to read this file

- **Kind**: orchestra / strings / chamber / piano.
- **Arrangement copyright**: whether a *transcription* (not the PD composition)
  may still be protected. Comparator should match register/density/bass, not
  copy a living arranger’s inner voices.
- **Pair**: `pdmx_id` in `data/manifest.csv` the comparator should score against.

- **Arrangement copyright: FLAG.** Commons caption: *Wilhelmj's "Air on the G String"*. Comparator should treat it as **string-orchestra chorale/cantabile gold**, not as a license to copy Wilhelmj’s solo-violin layout if a different scoring is intended.
